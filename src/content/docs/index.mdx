## 这套内容如何组织

<CardGrid stagger>
  <Card title="项目是主线" icon="seti:folder">
    每个项目拥有独立目录，集中保存简介、架构、开发记录和更新日志。
  </Card>
  <Card title="日志是时间线" icon="calendar">
    适合记录一次完整的问题分析、技术实践或阶段总结。
  </Card>
  <Card title="随记是素材库" icon="pencil">
    不追求篇幅，先把值得保留的信息写下来，再逐步整理成长期内容。
  </Card>
</CardGrid>

:::tip[写作原则]
先留下可靠记录，再追求完整表达。所有内容都以 Markdown 保存，并由 Git 保留修改历史。
:::
