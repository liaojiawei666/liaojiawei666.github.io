这是本站本身的项目记录。目标是建立一套能够长期使用、容易维护并且可以持续积累的个人写作系统。

## 项目目标

- 同时支持项目文档、正式日志和短篇随记。
- 采用接近在线技术书籍的三栏阅读布局。
- 所有内容使用 Markdown 或 MDX 保存。
- 支持中文全文搜索、深色模式和移动端阅读。
- 推送到 GitHub 后自动发布。

## 技术方案

| 部分 | 选择 |
| --- | --- |
| 网站框架 | Astro |
| 文档界面 | Starlight |
| 内容格式 | Markdown / MDX |
| 全文搜索 | Pagefind |
| 版本管理 | Git / GitHub |
| 托管 | GitHub Pages |

## 内容模型

### 项目

项目是长期内容，重点记录背景、目标、设计、进度和复盘。

### 日志

日志按时间组织，适合完整描述一次开发过程或问题解决过程。

### 随记

随记用于快速保存短想法、命令、代码片段和工具技巧。
